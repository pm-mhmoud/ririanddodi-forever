# Mahmoud & Riri — Minimal Media Edition

This version is intentionally designed around **words and interactions**, not a gallery.

It uses exactly:
- **1 photo**
- **1 video**
- **0 songs / background music**

## The only media files you need

### Photo
Put your chosen photo here:

`images/us.jpg`

This should be the one photo that means the most to you both. The website gives it its own chapter.

### Video
Put your video here:

`videos/our-video.mp4`

Recommendation: record a direct 60–90 second birthday message to Riri rather than making a montage. It will feel more personal and fits the website better.

## Personalize the writing

Open `siteContent.js`.

That file contains:
- relationship start date
- story timeline
- the caption/story behind your one photo
- reasons you choose her
- place memories
- quiz questions
- letters
- rituals
- future plans
- video text
- final birthday reveal
- final love letter

Search for `TODO MAHMOUD` and replace each placeholder with your real story.

## Deploy to GitHub Pages

Upload the files in this folder to your repository. The included `CNAME` contains:

`mahmoudandririforever.com`

Then enable GitHub Pages for the repository.

Important: GitHub Pages is public. `noindex` asks search engines not to index the page, but it is not password protection.
